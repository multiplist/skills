# Save an author or reader mark

1. Read the identified Source and determine the intended role. Use add_annotation for its author's own mark; use add_marginalia for a later reader's correction, tension, evolution or commentary. Account ownership alone does not establish original authorship. Avoid the deprecated annotate_source route.
2. Use the supplied mark text and real Source ID. If the user asks you to compose the comment, write it from the authorized context. Clarify missing source, meaning or authorship only when it affects the write.
3. Follow the current attribution schema. Prefer authenticated attribution where supplied. If scribe is required, use a verified identity appropriate to the actual author or later mind; never fabricate identity or treat a caller label as authentication.
4. Read back the source-linked marks, using the structured mark/seed view when available. Verify the actual mark ID, kind, content and attribution. Reconcile an uncertain write before retrying.

Use [primitive distinctions](../multiplist-orient/references/primitives.md) when counts or extraction state are ambiguous. An annotation is an authored primitive, not a golden-passage extraction. Saving a mark does not establish that extraction ran or that research included it. An unattached note belongs in source capture.

Return the saved comment and Source title, with concise attribution. Include the actual mark and Source IDs when requested or needed for follow-up; use only service-returned links. If readback fails, say what was saved versus what remains unverified.
